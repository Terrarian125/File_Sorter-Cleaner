# 自動ファイル仕分け＆お掃除ツール (File Sorter & Cleaner)

PythonとTkinterで作られた、デスクトップやダウンロードフォルダをワンクリックで綺麗にするデスクトップアプリケーションです。
ファイルの経過期間に応じた仕分けや、不要になったインストーラー・解凍済みZIPの自動ゴミ箱ポイ機能を備えています。

## 💡 主な機能

- **期間指定の自動仕分け**: 「すべて」「1日経過」「1週間経過」など、指定した期間放置されたファイルだけを対象に、拡張子ごと（Images, Documents, Archives, Others）に自動でフォルダを作って仕分けます。
- **安全な重複リネーム**: 移動先に同名のファイルがある場合、上書きせずに `_copy1`, `_copy2` と自動で名前を変更して保護します。
- **解凍済みZIPのお掃除**: 同名の解凍フォルダがすでに存在しているZIPファイルを自動で検出します。
- **使用済みインストーラーの駆除**: ファイル名に `setup` や `install` などのキーワードが含まれる `.exe` / `.msi` ファイルを自動で検出します。
- **完全安全設計（ゴミ箱ポイ）**: 不要ファイルは直接削除せず、Windows/Macの「ゴミ箱」へ送るため、万が一の誤削除でも救出可能です。
- **空フォルダの自動削除**: ファイル移動によって中身が空っぽになった不要なフォルダを自動でクリーンアップします。
- **処理ログの自動出力**: 実行するたびに、対象フォルダ内に `sort_log.txt` を生成し、「いつ、何をどこに移動/削除したか」の履歴を残します。

## 🛠️ 動作環境

- Python 3.x
- Windows / macOS (GUI環境)
